## Part B 训练与评测结果

| 项 | 值 | 出处 |
| --- | --- | --- |
| 训练配置 | batch 24 / 12000 步 / lr peak 1e-4 cosine + 1000 warmup | `logs/23-train-smolvla.log` |

| loss | **1089.2 → 0.019**（1000 步处断崖 = 常量维度被学会） | `artifacts/train_loss.png` |
| **专家基线** | **40/40 = 100%**，步数 245/249/254 | `logs/26-expert-baseline.log` |
| SmolVLA @4000 | 35/40 = **87.5%**，CI [74.0%, 94.5%] | `logs/25-eval-ckpt4000.log` |
| SmolVLA @8000 | 40/40 = **100%**，CI [91.2%, 100%] | `logs/28-eval-ckpt8000.log` |
| SmolVLA @12000 | 39/40 = **97.5%**，CI [87.1%, 99.6%] | `logs/27-eval-ckpt12000.log` |
| VLA 成功时步数 | 中位 **185**（比专家 249 还快） | `artifacts/success_curve.png` |
| 失败形态 | 100% 是 `steps=400` 超时，`failed_stage_counts` 全空 | 同上 |

**报这组数字的三条纪律：**
1. **必带对照组**——专家也是 100%，那是上界，VLA 只能逼近
2. **必带置信区间**——40 次全对的 Wilson CI 是 [91.2%, 100%]，不是"绝对可靠"
3. **必说天花板**——4/8 动作维度是常量、评测与训练同分布、数据无纠错行为

**8000 vs 12000 的正确说法**：只差 1 集，区间完全重叠，**n=40 分辨不出 2.5 个百分点**，
只能说"未观察到显著差异"，不能说"过拟合"。而 4000→8000 区间几乎不重叠，那是真提升。

| --- | --- |

| torch **cu126** wheel（镜像已缓存） | ~2500 KB/s |
| aria2c 16 线程（带正确 UA） | **15 MB/s** 峰值，5 MB/s 稳定 |
| aria2c 不带 UA | **全部 403** |
| Git LFS 直连 GitHub | 卡死（LFS 对象在 S3，直连不通） |
| Git LFS 走代理 + `concurrenttransfers 32` | 可用 |
| hf-mirror 单流 | ~2.3 MB/s |

## 三个最值得讲的"坑"

1. **`CONTROL_FAILED` 的根因在 Python 解释器**（shebang `#!/usr/bin/python3` vs SDK 装在 Conda）
2. **权重下完了但 sha256 不对**（跨镜像 `--continue` 续传产生空洞，safetensors 照样能打开）
3. **8 维 action 里 4 维 std=0**（专家不转手腕，数据多样性不足）
